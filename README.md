# AI-first-Developer-2.0-
# Лаборатория нестабильных порталов

Веб-приложение для просмотра информации о порталах.
Для Смотрителя и Мастера порталов так же доступны: принимание решения о состояние порталов, просмотр журнал событий и создания/удалениия порталов.


## Возможности

- Список порталов с поиском, фильтром по статусу и сортировкой.
- Расчёт риска портала по формуле `энергия × (1 − стабильность)`.
- Оценка времени до схлопывания портала (зависит от риска и энергии).
- Карточка портала: детали, риск, время до схлопывания, рекомендация, история изменений.
- Действия: стабилизировать, открыть, закрыть, отправить наблюдателя, пометить «под вопросом».
- Запреты: нельзя стабилизировать закрытый портал, нельзя отправлять наблюдателя при критическом риске, нельзя закрывать портал с существами внутри.
- Архив порталов: мастер может архивировать, разархивировать и удалять.
- Журнал событий: отдельная вкладка с поиском и фильтром по дате, хранение за последние 30 дней.
- Итоговая сводка: сколько открыто, критичных, закрыто, в архиве.
- Три роли: гость (просмотр), смотритель (действия), мастер (создание и архив).
- AI Worklog — встроенная вкладка.


## Запуск локально

1. Установи Python 3.10 или новее.
2. Установи Streamlit:
    py -m pip install streamlit
3. Перейди в папку проекта:
    cd portal_lab
4. Запусти приложение:
    py -m streamlit run app.py
5. Если после этого страница  в браузере сама не открылась:
    Открой в браузере `http://localhost:8501`.

## Роли

- **Гость** — просмотр порталов, без действий.
- **Смотритель** — управление порталами (стабилизировать, закрыть, открыть, наблюдатель, под вопросом).
- **Мастер** — всё то же плюс создание порталов, архивация, разархивация, удаление, доступ к вкладке «Журнал».

Роль выбирается в боковой панели.


## Формула риска
риск = энергия × (1 − стабильность)
- `энергия` — от 0 до 100.
- `стабильность` — от 0 до 1.

Уровни:
- 0–25 — низкий (зелёный)
- 25–50 — умеренный (жёлтый)
- 50–75 — высокий (оранжевый)
- 75–100 — критический (красный)

При риске выше 80 показывается предупреждение «Портал скоро схлопнется».


## Время до схлопывания

Вычисляется по риску и энергии. Базовое время — от 30 дней (риск 25) до 1 часа (риск 100), делится на множитель, зависящий от энергии. Показывается с разбросом ±10% — в днях, часах или минутах, в зависимости от величины.


## Проверка (ручные сценарии)

Перед сдачей проверены следующие сценарии.

1. Пустой список порталов
- Открыть `data/portals.json`, заменить содержимое на `[]`.
- Перезапустить приложение.
- Ожидаемо: в разделе «Порталы» появляется сообщение «Ничего не найдено», селектбокс не отображается, приложение не падает.
- Вернуть исходные данные.

2. Портал с критическим риском
- Открыть «Пугающий Глаз» (энергия 95, стабильность 0.1).
- Ожидаемо: риск критический (красный), показывается предупреждение «Внимание! Портал скоро схлопнется», рекомендация «немедленно стабилизировать или закрыть».
- Время до схлопывания показывается в минутах.

3. Запрещённое действие: закрытие портала с существами
- Открыть «Северный маяк» (18 существ).
- Нажать «Закрыть портал».
- Ожидаемо: ошибка «Нельзя закрыть портал: внутри 18 существ». Статус не меняется.
- Открыть «Забытый замок» (0 существ) — закрытие работает.

4. Изменение риска после стабилизации
- Открыть «Загорится» или любой портал с высоким риском.
- Записать значение риска до.
- Нажать «Стабилизировать».
- Ожидаемо: стабильность выросла на 0.3 (но не выше 1.0), риск уменьшился, цвет мог смениться на более зелёный, статус стал «стабилизирован».
- В журнале появилась запись.

5. Журнал действий после нескольких операций
- Войти как мастер.
- Выполнить 3–4 действия: стабилизировать, пометить «под вопросом», создать портал, разархивировать.
- Перейти в раздел «Журнал».
- Ожидаемо: все действия отображаются с датой и временем, самая новая запись сверху.
- Проверить фильтр по дате: указать сегодняшнюю дату «С» и «По» — останутся только сегодняшние записи.
- Проверить поиск: ввести имя портала — останутся только записи про него.

6. Роли
- Выйти (стать гостем) — в карточке портала нет кнопок, нет истории, рекомендации скрыты, раздел «Журнал» недоступен.
- Войти как смотритель — кнопки действий есть, создания портала нет, журнал недоступен.
- Войти как мастер — всё доступно: кнопки, создание, архив, журнал.

7. Уникальность имени при создании
- Войти как мастер, перейти в «Создать портал».
- Ввести имя, которое уже есть в активных или архиве.
- Ожидаемо: ошибка «Портал с именем «...» уже существует». Новый портал не создаётся.
- Ввести уникальное имя — портал создаётся, появляется в списке, в журнале запись.

8. Архивация и разархивация
- Войти как мастер.
- Выбрать портал, нажать «В архив».
- Ожидаемо: портал исчез из активных, появился в архиве.
- В архиве выбрать его, нажать «Разархивировать».
- Ожидаемо: вернулся в активные, запись в журнале.
